# Yomiko Backend Changelog

All notable backend changes will be documented in this file.

The project follows semantic versioning.

---

# [1.0.0] — Stable Release

Status: Completed

### Added

- Modular FastAPI backend
- PDF ingestion pipeline
- Recursive text chunking
- Sentence Transformer embeddings
- FAISS vector database
- Semantic Top-K retrieval
- Groq LLM integration
- Prompt builder
- Multi-document workspace
- REST API for upload, chat and document management
- Page citation support

---

# [2.0.0] — Development Begins

Status: In Progress

Date: 19 August 2026

### Planned

- Multi-format document support
- Multi-document upload & unified querying
- OCR support for scanned PDFs

### Notes

Version 2 focuses exclusively on strengthening the backend ingestion and retrieval architecture before introducing advanced retrieval techniques such as reranking.
